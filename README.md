# Website P06 — Risiko AI/LLM dan Prompt Injection

## Menjalankan lokal
1. Ekstrak folder ini.
2. Buka `index.html` dengan browser modern.
3. Pastikan folder `assets` tetap sejajar dengan `index.html`.

## Upload ke GitHub
Unggah `index.html` dan folder `assets` ke root repository.

## Deploy ke Netlify
Impor repository GitHub ke Netlify. Untuk website statis ini, biarkan Build command kosong dan gunakan root (`.`) sebagai publish directory. Pastikan `index.html` ada di root repository.

Semua file CSS, JavaScript, dan gambar yang diperlukan berada di folder `assets`. Jangan unggah API key atau data rahasia ke repository.
